COMO SUBIR
1. Extraia este ZIP.
2. Copie TODO o conteúdo desta pasta.
3. Cole dentro da sua pasta SUN-ICE-GIT-RAIZ.
4. Escolha Substituir os arquivos no destino.
5. No terminal, dentro de SUN-ICE-GIT-RAIZ:
   git add .
   git commit -m "Versao final estavel v9"
   git push
6. Espere o novo deploy do Netlify ficar verde.
7. Abra o site com Ctrl+F5.
8. Teste /painel.
